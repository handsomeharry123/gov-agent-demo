# 政策直达与招小慧解读

## 入口与页面

官网 `/website/pud` 顶部“政策直达”和下方同名服务入口，跳转 `/website/pud/policyretrieval`。官网版招小慧导航也已打通该入口。

以客户截图及 https://pyd.pudong.gov.cn/website/pud/policyretrieval 为参照，复用官网横幅、分类图标字体、平台标识和固定服务栏图片；还原金色政务头部、搜索栏、平台导航、政策级别页签、分类、七组条件、列表、排序、收藏和分页。区级显示分类及完整筛选，市级和国家政策按官网仅显示部门与年份筛选。区级分类映射取自官网实际筛选结果，不按标题猜测。滚动后平台导航切换白底。

## 新增交互

每条政策标题后增加“AI解读”，与收藏、兑付区分。点击后打开右侧560px抽屉，小屏使用全屏宽度；遮罩、关闭按钮和Esc均可退出，保留列表筛选和滚动位置。

抽屉始终展示当前政策名称及发布部门，包含要点、状态、时间、支持上限、适用对象、支持标准、申报条件及来源。首屏10项政策已整理官网详情，专业服务券等政策同时呈现比例、上限、交易发生时间等限制。未整理详情的政策明确提示查看官网，不编造资格、材料或补贴标准。切换政策重置追问，避免上下文串用。

提供时间、金额、咨询电话快捷追问和文本输入；当前为本地字段匹配演示，并非实时大模型对话。不支持的问题明确说明范围并引导官方来源。收藏使用独立localStorage键，不混用工作台会话。

## 数据与接入边界

政策列表为2026年11月5日从公开官网取得的698条离线快照：区级400条、市级224条、国家74条。保留政策批次作为唯一标识，避免同政策不同批次被误合并。详情链接保留官网specialBatchId、specialId参数。申报状态按上海时区当前日期计算。

实时政策更新、服务端收藏、登录、在线申报与大模型服务尚未接入。兑付跳转对应官网详情，不在演示环境提交申请。在线咨询、进度、帮助提供官网跳转；客服电话提供拨号。

生产接入应由后端按政策批次ID取得版本化正文、附件和有效期，返回带来源与条款位置的结构化解读；服务失败时保留原文入口并支持重试。模型不得把最高上限当作企业必得金额，不得根据标题推断申报资格。新增接口独立于原AI工作台会话，确保关闭或切换抽屉不改变独立页面。

## 代码隔离与验证

新增PolicyRetrieval组件、policyRetrieval.css、policySnapshot.json及官网静态素材；仅修改官网入口、官网版助手导航与路由，未修改原HomePage和BasicLayout。

构建执行 `npm run build`。浏览器验证包含首页入口、三类政策数量、搜索、筛选、排序、分页、收藏、逐项解读、来源链接、追问、关闭恢复、手机端宽度和现有官网AI入口。截图保存在 `002.前端代码/artifacts/policy-retrieval/`。

验收应以同视口逐项对照为准。本次已复用主要官网素材与布局，但尚不能承诺所有像素和全部官网业务服务完全一致；最终正式环境仍需客户确认字体、浏览器缩放及接入数据。

最终验证：区级400条、市级224条、国家74条；科技创新分类66条、市商务委筛选39条。390px手机抽屉无横向溢出，浏览器未捕获页面异常，生产构建通过。
