# 浦易达官网接入招小慧

本次新增 `/website/pud` 与官网内嵌助手 `/website/pud/policyAI`，保留 `/login` 和 `/app/home/overview`。登录页提供官网入口，助手页提供返回官网入口，根地址保持原行为。

官网首屏按照客户截图的结构适配：上海一网通办金色页头、地区搜索行、浦易达导航、浦东航拍视频、白色品牌标识、半透明搜索容器、热门搜索、智能推荐和悬浮服务。Logo 和航拍视频取自客户公开官网，存入本地资源，运行时无需依赖官网素材服务。移动端收拢导航并调整输入区及卡片布局。

入口规则：
- 搜索框“AI问答助手”替换为“招小慧 智能助手”。空输入点击进入官网内嵌助手；有输入点击、回车或搜索按钮进入官网内嵌助手并自动发送问题。
- 悬浮“在线咨询”替换为“招小慧 / 智能咨询”，进入同一助手。
- 热门搜索、政策匹配、企业信息、申报进度均携带对应意图进入官网内嵌助手，不创建另一套回复系统。
- 问题以路由状态传递，不放入 URL；首次消费后清除，避免刷新重复发送。
- 政务顶栏链接指向外部官方页面；平台导航定位本页服务板块。

范围与验收：
- 官网为本地演示适配页，下方服务板块为适配内容，并非官网全部子页面复刻。
- 对话、文件、技能等能力沿用当前 Demo；不代表已对接客户生产政策库、单点登录或真实申报进度接口。
- TypeScript 与 Vite 生产构建通过。已通过 Playwright 验证官网入口、双入口对话、侧栏折叠、连接器、技能、新建自动化任务路径，以及 1440px 桌面和 390px 手机布局。官网外框按截图适配，不宣称像素级一致。
- 后续验收重点：桌面首屏比例、航拍自动播放、四种提问触发方式、返回官网、移动端不横向溢出，以及原独立入口功能回归。


## 输入区增强

- 与工作台一致的四个对话场景：空间智能匹配、招商方案生成、政策精准测算、项目快速研判。点击后填入现有场景示例，确认发送时携带场景标识，避免仅依赖关键词误判。
- 默认输入提示统一为“向招小慧提问，描述您的业务需求”。
- 官网与工作台共用浏览器中文语音识别 Hook。点击麦克风启动，点击停止结束，转写结果允许修改后发送。录音期间官网禁用发送与场景切换；离开页面自动释放识别实例，最长 60 秒自动停止。
- 语音依赖浏览器 SpeechRecognition / webkitSpeechRecognition 和浏览器语音服务，需麦克风授权及 HTTPS / localhost。未接入服务端语音识别，不支持的浏览器提供文字输入提示。权限拒绝、无语音、设备缺失与网络异常均显示可理解的提示。
- 已通过生产构建及桌面/移动端截图检查；真实麦克风授权与转写仍需设备实测。


## 官网区域内嵌适配（2026-11-05）

- 官网助手地址：`/website/pud/policyAI`。首页搜索、悬浮咨询及业务推荐均进入该页面；首页携带的问题自动发送。
- 独立助手地址：`/app/home/overview`，保持原框架；官网右上角可在新标签页打开独立页，原官网标签中的对话保留。两页当前会话分别管理，不提供跨页会话同步。
- 官网保留金色政务页头、地区栏、蓝色平台导航及页脚；截图红框内直接复用 `HomePage`，不另建聊天逻辑。保留智能体切换、历史会话、连接器、技能、自动化任务、快捷场景、附件、模型选择、工作空间及语音入口。
- `useWorkspaceNavigate` 根据当前入口适配二级路径，技能管理、自动化模板、新建任务和返回操作继续留在官网框架。独立页面原有路径保持有效。
- 桌面支持侧栏折叠；手机使用原有工作台抽屉，数据卡片横向浏览，输入区置于对话卡片底部，消息独立滚动。
- 验证结果：双入口发送及回复通过，运行时无页面异常；390px 手机页面宽度等于视口宽度；生产构建通过，存在原有大包体积提示。
- 本次仅修改本地项目，未发布到客户公网。生产 AI、统一登录、真实数据及权限服务仍需对接。
