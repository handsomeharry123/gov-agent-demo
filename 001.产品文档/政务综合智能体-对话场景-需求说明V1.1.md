# 政务综合智能体-对话场景-需求说明V1.1

## 一、智能体定位

### 智能体名称

**招小慧**

### 一句话描述

> 政策 · 空间 · 产业 · 招引 · 研判 · 决策，一句话就能办
> 

六个关键词对应产品六大核心能力，让用户一眼感知边界：

| 关键词 | 对应能力 |
| --- | --- |
| 政策 | 三级政策全量匹配与奖补测算 |
| 空间 | 空间智能匹配，地图选址可视化 |
| 产业 | 产业链图谱，补链强链分析 |
| 招引 | 目标企业挖掘，投资信号监测 |
| 研判 | 项目快速研判，一页纸研判卡 |
| 决策 | 一企一策方案生成，辅助决策 |

## 二、设计背景与优先级说明

- **P0（吴总需求）**：Agent 工作步骤外显可感知、每条结论标注来源可取证、多域数据融合综合输出、内置技能中心入口
- **P0.5（戴老师需求）**：政策 × 企业 × 空间三库联动调用、一企一策方案结构化输出、空间地图可视化选址
- **演示原则**：只交付界面与交互 Demo，不做后端实现；每个场景须完整呈现「思考步骤 → 多库调用 → 结论 + 来源标注」链路

## 三、对话场景设计

### 场景一：空间智能匹配

> P0 核心旗舰场景 | 三库联动：企业库 × 空间库 × 政策库
> 

**1. 面向人群 · 场景 · 痛点 · 价值**

|  | 说明 |
| --- | --- |
| **面向人群** | 园区招商专员 / 政府办事窗口工作人员 |
| **典型场景** | 企业主动来询，提出入驻需求，工作人员需在短时间内给出空间推荐与政策匹配方案 |
| **核心痛点** | 空间台账散落各园区系统，政策文件几百条记不住；专员靠打电话问、翻 Excel 匹配，一个需求响应半天，说不清楚还容易漏配政策 |
| **产品价值** | 输入企业基本信息，30 秒内输出「空间推荐 + 政策清单 + 来源可溯」的完整方案，让刚入职的新专员也能对答如流 |

**2. 业务流程**

```
企业提出入驻需求（面积 / 行业 / 人员规模）
  → 智能体识别企业类型与产业属性
  → 匹配政策库（市级 / 区级 / 园区三级）
  → 筛选空间库（硬约束过滤：层高 / 承重 / 配电 / 消防）
  → 综合评分排序，输出 Top5 空间 + 政策清单
  → 工作人员确认后，可导出方案或转发给企业
```

**3. 进入场景后的欢迎语**

> 您好！我是招商 AI 助手。请告诉我企业的基本情况，包括**行业类型、所需面积、人员规模**，以及对空间的特殊要求（如层高、独立门头、配电需求等），我将为您快速匹配最合适的入驻空间，并同步推送可申请的政策支持。
> 

**4. 对话场景示例**

| 轮次 | 角色 | 对话内容 | 系统动作 / 组件 |
| --- | --- | --- | --- |
| 1 | 用户 | 有家做新能源汽车零部件的企业，想在浦东设华东研发中心，需要独立整层约 2000㎡，员工 80 人左右，对层高没有特殊要求。 | 文本输入框提交 |
| 1 | 智能体（思考步骤） | 收到，正在为您匹配…… 🔍 读取企业库 — 识别为「新能源汽车 · 零部件研发」类企业，属于浦东重点支持产业方向；📋 检索政策库 — 命中市级 / 区级 / 张江园区政策共 7 条；🏢 筛选空间库 — 全区 2000㎡左右整层空间共 23 处，按适配度排序 | 思考步骤气泡（流式外显）；企业库 + 政策库 + 空间库三库并发调用 |
| 1 | 智能体（结论） | 为您推荐 Top 3 空间：①张江科学城 A 座 8F / 2100㎡ ¥5.2元/㎡/天，整层独立；②金桥产业园 3 号楼 5F / 1980㎡ ¥4.8元，地铁 500 米；③外高桥科创园 B 栋 3F / 2050㎡ ¥4.5元，综合成本最低。可匹配政策 7 条（示例：研发机构落地补贴最高 80 万元 / 人才安居补贴每人每月最高 2000 元，均标注来源文号）。 | 空间推荐卡片列表；「查看地图」按钮 → 地图选址可视化组件；政策清单折叠展示，每条标注来源文号 |
| 2 | 用户 | 第一个空间的具体楼层信息能看看吗？ | 点击卡片「查看详情」或输入文本追问 |
| 2 | 智能体（结论） | 张江科学城 A 座 · 8 楼详情：建筑面积 2100㎡，实用率约 75%；精装交付，配备中央空调；配电容量 200kVA（可扩容至 400kVA）；车位配比 1:100㎡，共 21 个；园区食堂 + 人才公寓步行 5 分钟。 | 空间详情展开卡片；数据来源角标：空间库（含更新时间） |

### 场景二：招商方案生成

> P0 | 三库联动：产业链图谱 × 空间库 × 政策库
> 

**1. 面向人群 · 场景 · 痛点 · 价值**

|  | 说明 |
| --- | --- |
| **面向人群** | 招商局项目经理 / 园区重点客户经理 |
| **典型场景** | 对接一个有意向的重点企业，需要在 1-2 天内准备一份完整的「一企一策」招商方案用于谈判或领导审批 |
| **核心痛点** | 方案手工撰写需 3-5 个工作日，涉及产业契合论证、空间匹配、政策包测算、风险评估等多个模块，口径不统一、数据易出错，且难以快速响应企业的追问 |
| **产品价值** | 输入企业基本信息，1 小时内生成结构完整、数据可溯源的招商方案初稿，支持在线编辑后直接用于上会汇报 |

**2. 业务流程**

```
输入企业名称 / 项目简介（行业 / 投资规模 / 用地需求）
  → 产业链图谱定位：识别企业在产业链中的位置与本地缺口
  → 空间库筛选：按硬约束（单层 / 承重 / 配电）过滤 + 软约束打分
  → 政策库三级叠加测算：市级 + 区级 + 园区，输出 3 年综合奖补估算
  → 风险扫描：合规 / 市场 / 竞争风险自动提示
  → 整合生成「一企一策」方案文档，支持在线编辑与导出
```

**3. 进入场景后的欢迎语**

> 您好！请提供目标企业的基本信息——**企业名称或所属行业、拟投资规模、用地 / 用房需求**，我将为您生成一份包含产业契合分析、空间推荐、政策包测算、风险提示的完整招商方案，可直接用于项目汇报。
> 

**4. 对话场景示例**

| 轮次 | 角色 | 对话内容 | 系统动作 / 组件 |
| --- | --- | --- | --- |
| 1 | 用户 | 苏州有家做精密结构件的企业，想在长三角扩产，投资规模 1.5 亿，需要单层厂房约 2 万㎡，员工 300 人。帮我生成一份招商方案。 | 文本输入框提交 |
| 1 | 智能体（思考步骤） | 正在生成方案，预计需要 60 秒…… 🔗 产业链定位 — 识别为「新能源汽车 · 电池结构件」环节；📊 本地缺口分析 — 浦东该环节现有企业仅 2 家，处于明显缺链状态；🏭 空间筛选 — 全区符合硬约束的 2 万㎡单层厂房共 4 处；💰 政策测算 — 三级政策叠加，3 年综合奖补约 1860 万元 | 思考步骤气泡（流式外显）；产业链图谱 + 空间库 + 政策库三库并发调用 |
| 1 | 智能体（结论） | 《XX 项目一企一策招商方案（草稿）》：①产业契合度 92 分（强链优先），缺口率 76%，可带动产业产值约 8 亿元；②空间方案 3 套（方案 A 推荐：临港重装备产业区 1 号厂房 21000㎡，层高 12m，配电 3000kVA，¥18万/月；方案 B：金桥产业园 19500㎡ ¥15万；方案 C：外高桥保税区 20500㎡ ¥16万）；③政策包 3 年综合奖补约 1860 万元（市级设备投资补贴 / 区级租金补贴 / 园区人才住房补贴，均标注来源文号）；④风险提示：方案 B 排污指标余量不足；周边城市竞争性政策提示。 | 一企一策方案文档结构化输出；空间方案对比表格；政策包明细含来源角标；风险提示高亮；「在线编辑」「导出 PDF」双按钮 |
| 2 | 用户 | 方案 A 的政策申报材料清单能生成一下吗？ | 文本输入框追问 |
| 2 | 智能体（结论） | 方案 A 对应政策申报所需材料如下（共 11 项）：1. 企业营业执照副本（加盖公章）；2. 近 3 年审计报告……（完整清单可一键导出为 PDF） | 申报材料清单结构化列表；「一键导出 PDF」按钮 |

### 场景三：政策精准测算

> P0 | 政策库深度单域场景 + 连续追问演示
> 

**1. 面向人群 · 场景 · 痛点 · 价值**

|  | 说明 |
| --- | --- |
| **面向人群** | 企业服务专员 / 招商局政策对接岗 |
| **典型场景** | 企业来询「我能享受什么政策、能拿多少钱」，工作人员需快速给出准确答复 |
| **核心痛点** | 政策文件几百条，市级 / 区级 / 园区口径各不同，专员记不住、算不准，历史上平均漏配率超 30%，企业少拿了钱还不知情 |
| **产品价值** | 输入企业画像，秒级全量匹配三级政策，逐条给出奖补金额测算与申报材料清单，零漏配、有据可查 |

**2. 业务流程**

```
输入企业基本画像（行业 / 规模 / 注册地 / 认定资质）
  → 全量遍历市级 / 区级 / 园区三级政策库
  → 按企业画像逐条匹配，过滤不适用条款
  → 计算各条政策奖补金额（含叠加规则与上限）
  → 输出政策清单 + 奖补测算表 + 申报材料清单
  → 支持追问（如「换注册地」「扩大规模」等变量调整）
```

**3. 进入场景后的欢迎语**

> 您好！请告诉我企业的基本情况——**所属行业、注册地、企业规模（营收 / 员工数）、已有资质认定**（如高新技术企业、专精特新等），我将为您全量匹配可申请的政策，并测算每项预计可获得的奖补金额。
> 

**4. 对话场景示例**

| 轮次 | 角色 | 对话内容 | 系统动作 / 组件 |
| --- | --- | --- | --- |
| 1 | 用户 | 我们是高新技术企业，去年营收 5000 万，研发投入 800 万，注册在张江园区。能享受哪些政策？大概能拿多少钱？ | 文本输入框提交 |
| 1 | 智能体（思考步骤） | 正在为您检索…… 📂 遍历政策库：市级 42 条 / 浦东区级 67 条 / 张江园区 23 条，共 132 条；✅ 命中可申请政策：11 条（其中 3 条可叠加） | 思考步骤气泡（流式外显）；政策库全量遍历进度提示 |
| 1 | 智能体（结论） | 政策匹配结果（共 11 条，示例 3 条）：①高新技术企业研发费用补贴，研发投入 × 10% 约 80 万元，每年 3 月申报，沪科〔2024〕X 号；②张江园区落地补贴，一次性 50 万元，入驻满 1 年后申请；③人才安居补贴，每人每月最高 2000 元，滚动申报。合计预计可获奖补：约 210–280 万元/年。 | 政策清单结构化表格（含奖补金额、申报窗口、来源文号）；合计奖补金额高亮展示；「生成申报材料清单」按钮 |
| 2 | 用户 | 如果我们把注册地改到临港，政策会有什么变化？ | 文本输入框追问（变量调整） |
| 2 | 智能体（结论） | 张江园区 vs 临港新片区政策差异对比：企业所得税 15% → 9%（✅ 临港更优）；研发补贴上限 80 万 → 120 万（✅ 临港更高）；落地一次性补贴 50 万 → 80 万（✅ 临港更高）；人才住房配套：一般 → 专项人才公寓保障（✅ 临港更优）；通勤便利性：地铁直达 → 距市区约 75km（⚠️ 需评估）。综合评估：若贵司核心产业符合临港重点支持目录，建议重点考虑临港。 | 双园区政策对比表格；差异项差值高亮；综合建议摘要卡片 |

### 场景四：项目快速研判

> P0 | 一线招商专员高频日常场景
> 

**1. 面向人群 · 场景 · 痛点 · 价值**

|  | 说明 |
| --- | --- |
| **面向人群** | 招商局项目经理 / 分管领导（汇报前快速准备） |
| **典型场景** | 突然收到一个项目意向，需在 24 小时内给出是否值得跟进的初步判断，并形成可对内汇报的一页纸材料 |
| **核心痛点** | 项目尽调靠人工网搜 + 打电话，快则 1-2 天，慢则一周；结论靠经验拍板，没有量化依据，出问题了说不清楚 |
| **产品价值** | 输入企业名称，30 秒完成自动尽调，输出含产业契合度、效益测算、风险等级的一页纸研判卡，结论有据可查，直接可用于上会 |

**2. 业务流程**

```
输入企业名称 / 项目简介
  → 自动尽调：工商 / 股权 / 专利 / 招投标 / 涉诉信息抓取
  → 产业契合度评分：与本地产业链缺口匹配程度
  → 落地效益测算：投资额 / 年产值 / 税收 / 新增就业
  → 风险扫描：合规风险 / 市场风险 / 履约风险
  → 生成一页纸研判卡，支持导出 PDF
```

**3. 进入场景后的欢迎语**

> 您好！请提供项目的基本信息——**企业名称（或所属行业）、拟投资规模、主要业务方向**，我将在 30 秒内完成自动尽调，输出一份包含产业契合度、效益测算与风险等级的研判卡，可直接用于内部汇报。
> 

**4. 对话场景示例**

| 轮次 | 角色 | 对话内容 | 系统动作 / 组件 |
| --- | --- | --- | --- |
