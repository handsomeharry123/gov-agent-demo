# 招小慧五场景演示验收说明

依据需求说明 V1.2 更新，主线为「提出业务问题 → 展示处理步骤与数据源 → 输出业务结论 → 生成可操作成果 → 继续追问」。保留空间、方案、政策、研判四个场景，新增招商成效统计；备选场景不替换主线入口。

## 场景与交付体验

| 场景 | 用户任务 | 交互链路 | 验收重点 |
| --- | --- | --- | --- |
| 空间智能匹配 | 为新能源汽车研发中心匹配约2000㎡独立整层 | 企业、政策、空间检索 → Top 3 空间 → 地图选点 → 楼层详情 | 呈现面积、租金、配电和来源，未核验参数明确标注 |
| 招商方案生成 | 为投资1.5亿元的精密结构件项目准备一企一策 | 生成报告卡片 → 章节预览 → 追问扩写风险并补充推进建议 → V2 → 在线编辑 → Word导出／打印另存PDF | 报告有目录，版本变化可见；编辑后预览、Word导出和归档采用修改内容 |
| 政策精准测算 | 回答能享受哪些政策并提供企业材料 | 张江测算 → 临港变量对比 → 明确回到张江 → 生成Excel与Word文件卡片 → 在线预览 → 下载 → 我的文件 | 两种文件均为对应格式；Excel包含公式及来源；下载材料按23项准备清单组织 |
| 项目快速研判 | 为3亿元半导体封测项目形成初判 | 工商、股权、专利、信用、产业链步骤 → 一页纸研判卡 → 依据追问 → 打印另存PDF | 展示契合度、效益、风险及来源；企业全称缺失时不将模拟资质当作已核验事实 |
| 招商成效统计 | 为汇报生成全区招商态势大屏 | 一句话生成 → 缩略卡片 → 全屏打开／投屏模式 → 对话追加90天闲置预警 → 23处载体 → 点击详情 | 指标、地图、趋势、排行均可见；新增模块、地图标色和版本同步变化 |

## 推荐演示脚本

1. 空间智能匹配：发送默认需求，展开处理步骤，查看地图和推荐楼层，约2分钟。
2. 政策精准测算：发送默认画像，追问迁到临港的变化，再点击「就按张江园区……整理成文件」，预览并下载Excel和Word，约3分钟。
3. 招商方案生成：发送默认项目，打开章节预览，追问「把风险提示写详细一点，再补一章下一步推进建议」，查看V2，在线修改并导出，约3分钟。
4. 项目快速研判：发送默认项目，查看研判卡和取证清单，约1分钟。
5. 招商成效统计：发送默认问题，全屏打开，追加闲置预警并点击首条载体，约2分钟。

生成的报告和政策文件会归档至「知识中心 → 我的文件」，DOCX、XLSX文件可再次下载；大屏保存版本快照。归档依赖当前浏览器本地存储。

## 数据口径与演示边界

- 本次是前端交互Demo，多库检索步骤展示处理流程，不连接真实业务后台。
- 招商数据统一截止2026年11月5日。趋势、园区及产业项目数与126个签约项目保持一致；意向投资额趋势合计386亿元。
- PRD只提供11条政策命中总数与3条示例。测算表保留11条记录，记录4至11明确为待补原文；不编造剩余政策名称或金额。
- 研发费用800万元×10%=80万元可复算。210–280万元为演示初估区间；一次性50万元不作为每年重复收益；未补齐人才人数时不承诺总额。
- 材料清单包含23项分类准备材料。由于缺少11条完整政策原文，不声称已验证「去重9项」或逐政策强制要求。
- 不展示缺乏依据的「临港所得税9%」；迁移条件、产业目录、实质经营和叠加规则需正式核验。
- 地图为选址示意，23处闲置载体明细为模拟构造；来源材料和界面均标注演示口径。
- PDF通过浏览器打印另存；投屏为占满应用可视区的大屏布局，可配合浏览器全屏使用。大屏可通过对话追加闲置预警，其他指标提示补充数据。
